5. LOS 5 PROCESOS (parametrizar TODO en estos)
------------------------------------------------------------------------
1) VENTA/SUMINISTRO (COMERCIAL): cotización -> aprobación -> firma del
   cliente -> [oportunidad ganada + proyecto + pedido borrador a CT] ->
   compra -> entrega -> FACTURA CFDI -> cobro.
2) PROYECTO/OBRA (OBRA): levantamiento -> cotización multipartida -> firma ->
   proyecto (actividades, ingenieros, kit de herramientas, evidencias) ->
   factura por avance -> cobro.
3) PÓLIZA/SERVICIO (SERVICIO): propuesta -> contrato (SLA, cuota mensual) ->
   visitas programadas (órdenes automáticas) -> tickets/SLA -> factura
   recurrente.
4) LICITACIÓN (LICITACION): bases -> cotización con anexos y precios por
   rango -> fallo -> contrato -> ejecución -> facturación (uso CFDI gobierno).
5) OPERACIÓN INTERNA: asistencias -> pre-nómina -> PAGOS DE EMPLEADOS (SOLO
   CEO) · compras/almacén · contabilidad/CFDI.
Estado paso a paso (✅ existe / 🟡 a medias / ❌ falta): ver
MODELO-AUTOMATIZACION-PARAMETRIZADO.md.
