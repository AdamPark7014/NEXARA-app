## Android (100% nativo)

Stack: **Kotlin + Jetpack Compose + Navigation Compose**.

### Cómo abrir / compilar

1. Abre Android Studio → **Open** → selecciona `apps/mobile-native/android`
2. Android Studio generará/descargará lo necesario para Gradle.
3. Ejecuta el target `app`.

> Nota: este proyecto se creó intencionalmente sin archivos binarios del Gradle wrapper.
